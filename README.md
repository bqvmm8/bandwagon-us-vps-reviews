## 美国VPS线路：为什么不是所有"美国机房"都一样

很多人第一次买美国 VPS 踩的坑，不是配置不够，而是线路选错。同样标"美国洛杉矶"，走 CN2 GIA 和走普通国际出口，晚高峰体验能差出一个数量级。

美国到中国大陆的线路，按质量从高到低大致分这么几档：

- **CN2 GIA（AS4809）**：电信高端承载网，全程走 CN2，回程也走 CN2 GIA，延迟低、晚高峰丢包少。这是目前公认国内访问体验最好的线路。
- **CN2 GT**：去程走 CN2，回程可能走普通 163，比 GIA 差一截，但比纯国际出口好。
- **普通 163 / 国际出口**：走电信骨干网 163 出国，晚高峰容易拥堵，延迟波动大，便宜但体验看运气。
- **联通 9929 / 移动 CMI**：联通和移动各自的优质线路，单独看也不错，但三网都要稳的话还是 CN2 GIA 最省心。

搬瓦工能在中文圈子里站住脚，核心原因就是它家主打 CN2 GIA 线路，而且把电信、联通、移动三网回程都做了优化。下面具体看机房。
